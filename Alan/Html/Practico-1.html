Actividades 1

A.Navegador web: Software que interpreta archivos y permite acceder a la Web (ej: Chrome, Firefox, Safari).
b.Modelo Cliente-Servidor:Modelo donde las computadoras hacen "peticiones" y un equipo principal da "respuestas" a través de Internet.
c. Frontend: Parte visual de un sitio web. Se encarga de la estructura, formato y dinamismo utilizando HTML, CSS y Javascript.
d. Backend: Capa lógica que procesa información y datos. Utiliza lenguajes como PHP, Node, MySQL y Laravel.

Actividad 2

● !DOCTYPE>: No es una etiqueta, es una declaración en la primera línea que le indica al navegador el tipo de documento y la versión de HTML.
● body> Es la etiqueta principal que encierra y contiene a todo el código HTML de la página.
● head> Sección invisible para el usuario. Contiene información técnica, metadatos y el título de la solapa (title).
● html>: Sección que contiene todo el contenido visible que aparecerá en la página web.

○ Justificación: Los elementos en HTML deben cerrarse para que el código sea válido.

○ Justificación: La etiqueta br es una etiqueta de línea que no requiere cierre.

○ Justificación: HTML, CSS y Javascript son los lenguajes mas utilizados en el Frontend.

○ Justificación: HTML es un lenguaje de que arma la estructura, CSS es un lenguaje de estilo y Javascript es un lenguaje de programación.

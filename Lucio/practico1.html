4- Lee con atención cada afirmación. Coloca V si es verdadera o F si es falsa. Si es falsa, explica brevemente por qué.
1. (F) Un elemento en HTML siempre se compone únicamente de una etiqueta de apertura y el contenido, no hace falta cerrarlo.
○ Justificación: Los elementos en HTML deben cerrarse para que el código sea válido.
2. (V) La etiqueta br produce un salto de línea sin dibujar ninguna raya horizontal, y es de las pocas que no tiene etiqueta de cierre.
○ Justificación: La etiqueta br es una etiqueta de línea que no requiere cierre.
3. (V) HTML, CSS y Javascript son los lenguajes principales que se utilizan en el Backend.
○ Justificación: HTML, CSS y Javascript son los lenguajes mas utilizados en el Frontend.
4. (F) HTML es un lenguaje de estilo encargado de los colores y animaciones, mientras que CSS arma la estructura.
○ Justificación: HTML es un lenguaje de que arma la estructura, CSS es un lenguaje de estilo y Javascript es un lenguaje de programación.

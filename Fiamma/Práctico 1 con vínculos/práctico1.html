2- Observa las siguientes piezas clave que conforman un documento HTML. Escribe en la línea punteada la etiqueta correspondiente (, , , ) según la función que cumple.


  • !DOCTYPE: No es una etiqueta, es una declaración en la primera línea que le indica al navegador el tipo de documento y la versión de HTML.
  • html: Es la etiqueta principal que encierra y contiene a todo el código HTML de la página.
  • head: : Sección invisible para el usuario. Contiene información técnica, metadatos y el título de la solapa (title).
  • body: : Sección que contiene todo el contenido visible que aparecerá en la página web.

4- Lee con atención cada afirmación. Coloca V si es verdadera o F si es falsa. Si es falsa, explica brevemente por qué.
  1. (F) Un elemento en HTML siempre se compone únicamente de una etiqueta de apertura y el contenido, no hace falta cerrarlo.
    Justificación: En general, un elemento en HTML necesita tanto de etiquetas de apertura como de cierre, aunque hay excepciones como br y hr

  2. (V)La etiqueta br> produce un salto de línea sin dibujar ninguna raya horizontal, y es de las pocas que no tiene etiqueta de cierre.

  3. (F ) HTML, CSS y Javascript son los lenguajes principales que se utilizan en el Backend.
    Justificación: HTML y CSS se utilizan para el FrontEnd (la experiencia del usuario), mientras que lenguajes como Javascript se utilizan para el Backend.
  4. (F) HTML es un lenguaje de estilo encargado de los colores y animaciones, mientras que CSS arma la estructura.
    Justificación: HTML se utiliza para armar la estructura, y CSS para los colores y animaciones

6- Vas a programar una página web sobre u banda, artista, serie o videojuego favorito.

Para aprobar este proyecto, tu código debe cumplir con la siguiente "Lista de Requisitos":
